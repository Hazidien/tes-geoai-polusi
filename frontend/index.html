WebGIS Air Pollution

Information & tutorial penggunaan

WebGIS ini digunakan untuk mengeksplorasi Carbon Monoxide (CO) berbasis citra satelit Sentinel-5P melalui Google Earth Engine.

Cara menggunakan

  1. Pilih Module dan Variable. Pilih parameter polusi yang tersedia untuk dianalisis.
  2. Tentukan Start dan End. Masukkan periode waktu analisis yang diinginkan.
  3. Pilih Spatial aggregation. Gunakan Mean, Median, Minimum, atau Maximum sesuai kebutuhan.
  4. Buat AOI. Gunakan toolbar gambar Leaflet pada peta untuk membuat polygon atau rectangle.
  5. Jalankan analisis. Klik RUN ANALYSIS untuk memproses AOI dengan Google Earth Engine.
  6. Baca hasil. Statistik, jumlah citra, klasifikasi relatif, dan raster akan ditampilkan pada WebGIS.
  7. Mulai analisis baru. Klik CLEAR AOI, lalu gambar AOI baru dan jalankan kembali.
Catatan penting: nilai CO adalah satellite column number density dalam mol/m². Nilai ini bukan konsentrasi CO langsung di permukaan tanah dan bukan indeks ISPU.
