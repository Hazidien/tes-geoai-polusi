How to use this application

  1. Select the module and variable. The current analysis uses Sentinel-5P Carbon Monoxide (CO).
  2. Set the analysis period. Choose a start date and an end date. The end date must be later than the start date.
  3. Choose spatial aggregation. Mean, median, minimum, or maximum can be used for the selected AOI.
  4. Draw an AOI. Use the Leaflet-Geoman tools on the map to draw a polygon or rectangle.
  5. Run the analysis. Click RUN ANALYSIS to process the selected area with Google Earth Engine.
  6. Read the result. The map displays the CO raster and the panel reports the selected statistic and image count.
  7. Clear and repeat. Click CLEAR AOI before creating a new analysis area.
Important: CO shown here is Sentinel-5P satellite column number density (mol/m²). It is not a direct ground-level air-quality concentration.
