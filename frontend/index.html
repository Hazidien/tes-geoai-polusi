WebGIS Air Pollution — Sentinel-5P

WebGIS Purpose

This WebGIS is designed to map and analyze the spatial and temporal variation of Sentinel-5P air-pollution observations over a user-selected Area of Interest (AOI).

Available variables

Four pollutant analyses are available: Sulfur Dioxide (SO2), Nitrogen Dioxide (NO2), Carbon Monoxide (CO), and Methane (CH4), following the supplied Geoaccess training reference.

1. Select the period

Set the Start date and End date.

2. Select the chart interval

Choose Daily mean or Monthly mean.

3. Create an AOI

Draw a Polygon or Rectangle. Only one AOI is active at a time.

4. Run one analysis

Only the selected pollutant and selected spatial aggregation method are executed.

5. View the chart & download

The time-series chart can be opened and closed. The PDF report contains the analysis map, parameters, time series, and explanation.

Important: Sentinel-5P measurements are atmospheric observations and should not be interpreted as direct ground-station measurements or ISPU values.
