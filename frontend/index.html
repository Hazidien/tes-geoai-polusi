UI Guide & Analysis Method

Penjelasan setiap UI

Module

Menentukan jenis analisis. Versi ini hanya menjalankan Air Pollution.

Pollutant

Pilih satu: SO₂, NO₂, CO, atau CH₄. Hanya pollutant yang dipilih yang diproses.

Start date / End date

Menentukan periode akuisisi Sentinel-5P. End date ikut dihitung.

Time series interval

Monthly mean membuat satu nilai per bulan; Daily mean satu nilai per hari. Pilihan ini berlaku untuk chart dan PDF.

Spatial aggregation

Mean, Median, Minimum, Maximum adalah reducer untuk merangkum piksel valid di dalam AOI.

AOI drawing

Gunakan kontrol Polygon/Rectangle di kiri atas peta. AOI baru menggantikan AOI sebelumnya.

AOI Shapefile / GeoJSON

Upload ZIP Shapefile yang berisi .shp, .shx, .dbf dan sebaiknya .prj. GeoJSON Polygon/MultiPolygon juga diterima.

RUN ANALYSIS

Menjalankan satu analisis untuk satu pollutant + satu AOI + satu periode di Google Earth Engine.

CLEAR AOI

Menghapus AOI, raster hasil, result dan chart.

HIDE AOI / SHOW AOI

Menyembunyikan atau menampilkan batas AOI tanpa menghapus analisis.

HIDE ANALYSIS / SHOW ANALYSIS

Menyembunyikan atau menampilkan raster hasil Sentinel-5P tanpa menghapus statistik.

OPEN TIME SERIES

Membuka chart untuk pollutant dan parameter analisis yang terakhir dijalankan.

DOWNLOAD GEOTIFF

Mengunduh raster hasil sebagai GeoTIFF melalui backend berdasarkan AOI, periode dan resolusi 1113.2 m.

REVIEW PDF REPORT

Membuat laporan lalu membukanya di panel preview. PDF belum di-download sampai tombol DOWNLOAD PDF di panel review ditekan.

PDF Review

Panel review menampilkan PDF asli dalam viewer browser. Periksa peta, parameter dan chart terlebih dahulu, lalu pilih Download PDF atau Close.

Result

Menampilkan nilai statistik, unit, jumlah image, periode dan catatan interpretasi. Nilai adalah observasi atmosfer satelit, bukan pengukuran stasiun darat atau ISPU.

Map & color legend

Raster memakai gradasi warna berbeda untuk setiap pollutant. Legend kanan bawah menunjukkan rentang nilai dan unit pollutant aktif.

Status

Menampilkan proses upload, analisis GEE, chart dan status preview/download.

Metode sesuai referensi: Sentinel-5P ImageCollection → filter AOI/tanggal → pilih band → temporal mean → clip AOI → konversi satuan → agregasi AOI → time series pada 1113.2 m → GeoTIFF. SO₂/NO₂/CO mengikuti konversi mol/m² → µg/m³ pada referensi; CH₄ mengikuti ppb → ppm dengan membagi 1000.
