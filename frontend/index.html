How to use

  1. Select the analysis module and variable.
  2. Choose the start and end dates.
  3. Choose the aggregation method.
  4. Draw a polygon or rectangle on the map to define the AOI.
  5. Click RUN ANALYSIS to process the selected area.
  6. Use CLEAR AOI to remove the current area and draw again.

Important: CO is a satellite column number density from Sentinel-5P. It is not a direct ground-level air-quality measurement.
